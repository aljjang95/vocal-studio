# 변동 레슨 문자 연결

문자 일정 화면은 학생의 전화번호로 레슨생과 상담을 찾아 받은 문자와 직접 보낸 답장을 모읍니다. 학생에게 운영 달력이나 다른 학생의 정보를 공개하지 않습니다. 시간 결정과 답장은 선생님이 하며, 선택한 문자 카드에서 날짜와 시간을 확인한 뒤 등록합니다.

## 휴대폰 연결

1. 갤럭시 S26 Ultra에서 관리자 앱에 로그인하고 **문자 일정**을 엽니다.
2. 휴대폰 연결 앱을 내려받아 설치합니다. 이 앱은 스튜디오 전용으로 빌드한 Android 앱입니다.
3. 관리자 화면에서 연결을 만들고 전용 연결 주소와 연결 키를 휴대폰 앱에 입력합니다. 연결 키는 비밀번호처럼 취급하며 채팅이나 문자로 보내지 않습니다.
4. 휴대폰 앱에서 문자 읽기·수신·발신 권한을 허용하고 연결을 시작합니다.
5. 등록된 연락처의 시험 문자를 수신하고, 휴대폰에서 답장을 보낸 뒤 관리자 카드에 양쪽 문자가 들어오는지 확인합니다.
6. 월요일·화요일 안내 문구와 시각을 확인한 뒤 자동 안내를 켭니다.

새 연결을 만들면 이전 연결 키는 폐기됩니다. 연결 해제는 추가 발송을 중단합니다. 연결 앱은 시작 이후의 등록된 번호 문자만 전달하며 이전 문자함 전체를 가져오지 않습니다. 개인 인증 문자나 등록되지 않은 번호의 문자는 운영 문자 목록에 저장하지 않습니다.

## 월요일과 화요일

기본 시각은 한국 시간 월요일 오전 10시, 화요일 오후 2시이며 설정에서 변경할 수 있습니다. 월요일에는 이번 주 일정이 없는 수강 중 변동 레슨생에게 일정 요청을 준비합니다. 화요일에는 이미 답했거나 일정이 잡힌 학생을 제외해 부드러운 안내를 준비합니다. 휴대폰이 서버에 연결돼 요청을 받아야 실제 문자가 발신됩니다.

같은 주·학생·안내 단계의 요청을 반복해도 자동으로 중복 발송하지 않습니다. 발신 결과가 불확실한 문자는 재발송하지 않고 확인 상태로 남깁니다. 표시되는 발신 성공은 단말의 발신 결과이며 상대방의 수신·읽음 증거는 아닙니다.

## 일정 확인

문자의 날짜·시간은 후보입니다. "화요일 3시"처럼 오전·오후가 불명확하거나 여러 시간이 있으면 직접 확인합니다. 번호가 여러 학생과 연결돼 있으면 자동으로 한 명을 고르지 않습니다. 상담 별명이 같은 번호의 레슨생 이름과 다르면 이름 연결을 확인할 수 있습니다.

확인 등록은 현재 서버 자료를 기준으로 한꺼번에 처리합니다. 충돌이나 다른 기기의 변경이 있으면 등록을 멈추고 입력한 후보를 유지합니다. 기존 예약을 삭제하거나 대체하지 않습니다.

## 휴대폰 동작 범위

이 연결은 Android 일반 SMS를 대상으로 합니다. 채팅 메시지(RCS), 카카오톡, MMS와 첨부 파일은 별도 지원과 실기기 검증이 필요합니다. Android의 배터리·백그라운드 제한 때문에 서버 확인이 지연될 수 있으므로 정확한 분 단위 발송을 보장하지 않습니다. 연결 앱이 표시하는 최근 연결 시각과 실제 문자 수신·발신 결과로 상태를 확인합니다.

휴대폰 설치·권한·실제 수신과 발신·화면을 끈 상태의 지속 동작을 확인하기 전에는 실기기 연결 완료로 보지 않습니다.
